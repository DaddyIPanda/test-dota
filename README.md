# Test Dota 2

React-приложение для поиска игроков Dota 2 через OpenDota API.

## Как запустить проект

Для установки всех необходимых зависимостей выполните:

`npm install`

Чтобы запустить приложение в режиме разработки.
После запуска приложение доступно по адресу `http://localhost:3000`.

`npm start`

## Структура данного проекта

Главное что нужно знать о проекте - это 4 важных файла:

* `App.tsx` - основной компонент, получение данных из OpenDota API и отображение информации об игроке.
* `Input_field.tsx` - поле для ввода Steam ID и кнопка поиска.
* `index.tsx` - запуск приложения и подключение Chakra UI.
* `package.json` - содержит информацию о проекте, необходимые зависимости и команды для запуска, сборки и публикации приложения.

## Используемые технологии

В проекте использованы:

* React + TypeScript
* Axios
* Chakra UI
* Phosphor Icons
* OpenDota API
